### Intro :wave:
Hello! While packing for a camping trip :tent:, I was looking for my flashlight :flashlight:. While looking for it, I remembered that I own the Light Messenger add-on for my Flipper Zero. I knew that the app for this add-on already had a flashlight mode, but except for a solid white light, there was nothing special. I know that this add-on supports multiple different colors :rainbow:. Then an idea came to mind: What if I create my own flashlight and add a little twist to it? After some brainstorming with AI on how this could be done, I came up with this idea :bulb:.

### Introducing LightFlashPro

![](/images/lightflashpro/banner.jpg)

LightFlashPro was created with the help of Claude Code. Since I didn't want to reinvent the wheel, I used the [401 Light Messager](https://github.com/lab-401/fzLightMessenger/) repo. 
LightFlashPro was created with the help of Claude Code. Since I didn't want to reinvent the wheel, I used the [401 Light Messenger](https://github.com/lab-401/fzLightMessenger/) repo. 

![](/images/lightflashpro/main.png)

All modes have **Brightness**, which allows you to adjust how bright the light is. For almost all modes, you can set different colors. By default, I added 8 colors like white, green, red, cyan... You can also set up a custom color: simply select "Custom" and use the custom menu to change the RGB colors. 

![](/images/lightflashpro/custom_light.png)

Let's look into the modes now:
- **Solid** is pretty much self-explanatory.
- **Strobe** switches the light on and off at set intervals.
- **Pulse** is very similar to strobe, except the light slowly dims and brightens in intervals. 
- **SOS** sends an SOS signal. Speed can also be adjusted.
- **KnightRider** — who doesn't love K.I.T.T. from the Knight Rider show? :smile: 
- **Police** flashes between red and blue lights.
- **Sparkle** — since the Light Messenger has 16 LEDs, it randomly chooses a color on a random LED at random intervals. 

There is also a speed option for all modes except Solid mode. It allows you to control how fast the light shines.
